Quick win 16 of 28 · Neighbourhoods

What we're proposing

Each home size on a neighbourhood page shows its lowest live rent and how many are available.

Why

Neighbourhood pages describe each home size but not what it costs, so a renter has to leave the page and search to find out. The prices and counts already exist in the listings feed; showing the lowest rent and the number available for each size is a small template change that stays current by itself.
